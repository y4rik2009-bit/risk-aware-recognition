03 / WHY THIS IS INTERESTING

A guarantee has assumptions.

Calibration can lower the threshold until few true labels are missed. But lower thresholds also add false positives. Training through the calibration threshold attempts to improve that trade-off.

Now select noisy images with clean calibration. The input distribution changed. The old calibration no longer justifies its risk bound. Fresh labeled calibration can help, but often at a visible cost in extra answers.

What this page does

This is an explorer for completed experiments, not live model inference. Every control selects a measured configuration. The three budgets were fixed before evaluation.

The boards combine real UCI handwritten digits into a constructed multi-label task. This is not a medical evaluation or a reproduction of the paper's image-segmentation benchmark.
